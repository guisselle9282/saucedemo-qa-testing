# Test Evidence

Place the screenshots captured during the SauceDemo test session in this folder.

Use these filenames so they match the bug reports and the Excel test-case matrix:

- `BUG-001-ZIP.png` — screenshot showing an invalid ZIP value accepted by checkout.
- `BUG-002-Empty-Cart.png` — screenshot showing the empty-cart checkout behavior and/or the `$0.00` order overview with Finish enabled.

Only include screenshots that you personally captured during testing. If a screenshot contains personal or private information, remove it before publishing the repository.
